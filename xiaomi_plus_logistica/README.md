# Xiaomi Plus Logística

MVP mobile em Flutter para a operação logística da Xiaomi Plus, com identidade visual preto/laranja e foco em aparelhos de alto valor.

## Já implementado

- Login demonstrativo
- Home com indicadores operacionais
- Lista de entregas
- Filtros por status
- Detalhe de pedido
- Registro de produto, IMEI e serial
- Fluxo de coleta, rota e entrega
- Rastreamento visual demonstrativo
- Confirmação de entrega
- Perfil
- Tema Xiaomi Plus

## Rodar no computador

Entre nesta pasta e execute:

    flutter create --project-name xiaomi_plus_logistica .
    flutter pub get
    flutter run

O primeiro comando gera as pastas Android, iOS e Web ao redor do código existente.
